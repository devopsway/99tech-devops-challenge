# Context

A team ships a web product made of two applications:

- a **backend** — an HTTP API, deployed to **EC2**
- a **frontend** — a static single-page app, deployed to **S3**

Both are released manually today. Your task is to design and implement **production ready CI/CD pipelines using GitHub Actions** for both applications.

# Task

1. Design the pipelines.
2. Implement them as GitHub Actions workflows.
3. Decide what "production ready" means here, and make them that.

You do not need a real AWS account. Where something cannot actually run, implement it faithfully and explain what it would do.

# **Submission**

Submit your workflows, any supporting files, and a short report in `SOLUTION.md` covering:

- The assumptions you made and why
- How the pipelines work, and what you deliberately left out
